# KidoCode AI - Acuan AI Agent (Web Education for Kids)

## 1. Konteks Proyek
Platform web edukasi coding interaktif untuk anak SD (Sekolah Dasar) kelas 4-6. Fokus pada pengenalan logika dasar melalui UI/UX yang ceria, penuh warna, dan gamifikasi sederhana.

## 2. Tech Stack
- Frontend: Next.js (App Router), React, Tailwind CSS.
- AI: Prompt sistem khusus (KidoBot) dengan bahasa anak-anak.

## 3. Panduan UI/UX
- Palet Warna: Ceria dan kontras (Sky Blue, Amber, Emerald).
- Tipografi: Font Quicksand membulat, ukuran besar, dan mudah dibaca.
- Interaksi: Animasi hover ringan (scale), shadow 3D pada tombol.
