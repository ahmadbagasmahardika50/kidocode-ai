# Jurnal Prompt Terkurasi & Log Mentah
**Proyek:** KidoCode AI
**Kategori:** Umum (Web Education for Kids)

## A. Jurnal Prompt Terkurasi (Maks 5 Prompt)
1. **Ide & Landing Page:** "Buatkan `app/layout.tsx` menggunakan font Google 'Quicksand'. Setelah itu, tulis ulang `app/page.tsx` menjadi halaman depan KidoCode AI dengan hero section ceria (bg-sky-100), gaya tombol melingkar 3D, dan arahkan ke /playground."

## B. Log Prompt Mentah
- [Tahap 1] Setup awal framework dan pembuatan Landing Page.

2. **Pembangunan Ruang Belajar:** "Buatkan folder `app/playground` dan file `page.tsx` di dalamnya. Buatkan antarmuka layout 2 kolom responsif: Kolom kiri (bg-amber-50) berisi cerita misi menyelamatkan robot kucing. Kolom kanan berisi area logika dengan tombol blok puzzle (Maju, Belok, Ambil) yang memiliki efek klik 3D bergaya game. Gunakan React State untuk menampilkan urutan blok yang diklik anak."

3. **Finishing & Fitur AI:** "Buatkan komponen `app/components/KidoBot.tsx` berupa floating chat AI. Desain jendela chat menggunakan Tailwind dengan elemen UI anak-anak (warna cerah, rounded besar, shadow). Implementasikan simulasi chat sederhana menggunakan React State, di mana AI membalas dengan kata penyemangat ramah anak dan emoji. Pasang komponen ini secara global di `app/layout.tsx`."
